# 潮汐当铺 · Tide Pawnshop

外婆走了，留给你海边一间当铺和三百块的债。十天之内，看货、讨价、赶海，赶在七月十五——一年里最大的潮——之前把债还上。
落潮最低的那天，二十年前沉在黑礁外的望舒号会露出来。

**试玩：** https://kra607959.github.io/tide-pawn/ （电脑用鼠标，手机按住拖动）

## 怎么玩

- **看货**：客人把东西摆上柜面，用放大镜在盘子上细看。成色、款识、裂纹、假货的破绽，看出来一处，心里的估价就准一分。还能翻面、掂量。
- **讨价**：收当、收购、卖货都要还价。压得太狠客人会走；不识货的人你给多少他都认——给得公不公道，镇上的人都看着（口碑）。
- **当期**：当出去的东西到期有人来赎，本钱加二成；到期不来，东西归铺子。
- **赶海**：每天早上可以下滩。潮一天比一天大，越往后走得越远；潮水回来之前得上岸。海货傍晚卖给鱼贩，捡到的东西进库房。
- **何先生**：海燕号靠岸的傍晚（初六、初九、十二、十五），何先生按实价九折收货。
- **望舒号**：客人的东西、外婆的当簿、滩上挖出来的物件里藏着沉船的线索。十五夜，用你记下的凭据回答四个问题。
- 一共五个结局。

## 本地运行

只需要 Node.js（18 以上），没有依赖，不用安装。

```bash
node serve.mjs
```

然后打开 http://localhost:5300 。

## 工具

| 命令 | 用途 |
| --- | --- |
| `node --test tests/*.test.mjs` | 逻辑测试：数据完整、讨价还价、估价、存档、整局能玩完且结局都走得到 |
| `node tools/sim.mjs [局数]` | 让几种机器人掌柜（眼拙 / 寻常 / 老练，下不下滩，各个剧情选择）各玩若干局，看钱够不够、结局分布 |
| `node tools/sim.mjs --one 7` | 看某一局的逐日账目 |
| `node tools/shots.mjs` | 用无头 Edge / Chrome 按真实时钟玩几个场景并截图到 `shots/`（桌面 1280×720、手机 390×844） |

## 结构

```
index.html            页面骨架
src/main.js           一天的流程：早晨 → 下滩 / 开门 → 柜台 → 收市 → 十五夜
src/logic/            纯逻辑（node 里也能跑）：随机数、估价与讨价、状态与存档、赶海
src/data/             物件、人物、十天的安排、线索与当簿与结局的文字
src/story/            剧情客人和随机客人的脚本（同一套脚本给页面和机器人用）
src/art/              Canvas 程序绘制：铺子、人物、物件
src/ui/               柜台、放大镜盘、赶海、各种弹层
src/audio.js          WebAudio 合成的音效和海浪声
tools/                机器人掌柜、数值模拟、截图
tests/                node:test 测试
```

美术、音效全部由代码现场生成，没有外部素材。
